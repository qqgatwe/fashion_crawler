# Fashion Radar｜GU × UNIQLO 商品價格比較與視覺化分析

使用 Python 與 Selenium 蒐集 GU、UNIQLO 商品資料，透過 Pandas 進行資料清理與統計分析，並結合 Plotly 與 Streamlit 建立互動式資料分析儀表板（Dashboard），呈現兩個服飾品牌的商品結構與價格差異。

---

## 專案目的

比較 GU 與 UNIQLO 的商品價格及商品類型，透過實際蒐集的商品資料，分析兩個品牌在以下項目的差異：

- 商品數量與類型
- 商品類型占比
- 商品平均價格與中位數
- 商品價格區間分布
- 共同商品類型的平均價格
- 品牌間的價格差異

最後將分析結果整合至互動式 Dashboard，讓使用者能更直觀地探索商品資訊與價格分布。

|---|---:|
| GU | 200 |

### 資料欄位

蒐集與整理的商品資料包含：

- 商品品牌
- 商品名稱
- 商品編號
- 商品價格
- 商品類型
- 商品網址
- 資料蒐集時間

資料經過清理後，用於商品價格統計、類型分析及品牌比較。

---

## 資料清理與前處理

使用 Pandas 整理爬蟲蒐集的商品資料，主要處理內容包括：

**1. 價格格式轉換**

將商品價格轉換為數值格式，方便進行統計運算。

**2. 缺失值與無效資料處理**

排除價格缺失、無法轉換或價格無效的商品紀錄。

**3. 重複商品處理**

依據商品編號辨識重複紀錄，避免相同商品重複計入分析。

**4. 商品類型整理**

統一商品類型名稱，方便進行不同品牌之間的分類比較。

## 商品價格分析

### 1. 平均價格比較

| 品牌 | 平均價格 |
|---|---:|
| GU | 約 NT$610 |
| UNIQLO | 約 NT$959 |

在本次蒐集的商品資料中，UNIQLO 的平均價格約比 GU 高 **NT$349**。

### 2. 主要價格區間

**GU**

商品主要集中於 **NT$200～399**，約占全部 GU 商品的 **31.0%**。

**UNIQLO**

商品主要集中於 **NT$400～599**，約占全部 UNIQLO 商品的 **31.3%**。

整體而言，GU 商品較集中於低價區間，而 UNIQLO 在較高價格區間的商品占比相對較高。

### 3. 商品類型分析

在本次資料中，兩個品牌占比最高的商品類型皆為 T 恤。

| 品牌 | T 恤商品占比 |
|---|---:|
| GU | 32.5% |
| UNIQLO | 24.4% |

透過商品類型分析，可以進一步了解不同品牌的商品組成。

## Streamlit 互動式儀表板

使用 Streamlit 開發 **Fashion Radar** 互動式資料分析儀表板，整合商品統計、價格分析與品牌比較功能。

### Dashboard 主要功能

**總覽**

呈現商品總數、品牌平均價格及主要分析結果。

**商品類型**

分析商品類型數量與占比，了解兩個品牌的商品結構。

**價格分析**

比較商品價格區間、平均價格與中位數。

**品牌比較**

比較 GU 與 UNIQLO 在共同商品類型中的價格差異。

**商品探索**

提供商品搜尋與篩選功能，可依品牌、商品類型、商品名稱及價格範圍查詢商品。

**商品分析總結**

彙整主要統計結果與品牌價格比較資訊。

## 安裝與執行

### 1. 下載專案

下載 GitHub 專案後，使用 VS Code 或其他程式編輯器開啟專案資料夾。

### 2. 建立 Python 虛擬環境

```bash
python -m venv .venv
```

### 3. 啟用虛擬環境

Windows PowerShell：

```powershell
.\.venv\Scripts\Activate.ps1
```

### 4. 安裝必要套件

```bash
python -m pip install -r requirements.txt
```

### 5. 啟動 Streamlit Dashboard

```bash
streamlit run dashboard/dashboard.py
```

啟動成功後，即可透過瀏覽器查看互動式分析儀表板。

> 注意：啟動指令需與實際專案檔案位置一致，且必須具備 Dashboard 所需的商品資料檔案。

## 分析結果與結論

本次分析顯示，GU 與 UNIQLO 在商品價格上具有不同的分布特徵。GU 商品較集中於低價區間，而 UNIQLO 的平均價格相對較高。搭配圖表與互動式儀表板，能更直觀地呈現兩個品牌的價格差異。

整合 Python 網頁爬蟲、Pandas 資料分析、Plotly 圖表視覺化及 Streamlit 互動式儀表板，完成從資料蒐集、清理到分析與呈現的完整流程。
